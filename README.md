# qr-generator-official

**QR Generator** — a modern, multi-page QR code studio. Pure static HTML/CSS/JS: no build step, no dependencies, nothing to break.

Pages: `index.html` (home) · `studio.html` · `templates.html` (60 templates) · `about.html`

## Deploy on GitHub Pages
1. Create a repo named `qr-generator-official`, upload **all files in this folder** (keep the structure).
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
3. Open `https://<your-username>.github.io/qr-generator-official/`

Works offline too: just open `index.html`.
